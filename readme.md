## What was this?

This was an early iteration of a Contacts REST API built with:
- Node.js + Express
- Mongoose + MongoDB
- Docker (via `docker-compose.yml`)

The `assignments/contacts` branch contains the most recent work.

---

## Why deprecated?

The canonical implementation lives in `RESTfulRoutesUsingExpressJS`, which has:
- Passing tests
- Consistent API contract
- Proper error handling
- Clean documentation
